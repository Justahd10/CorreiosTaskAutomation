# Title
Automation of Correios report notifications

# Description
Automation of repetitive and sequential tasks in a customer service work.

# Functionalitys
1. Browser automation: keyboard, mouse, and image search
2. Access and edit spredsheet from Google Sheets
3. Tracking information lookup via API

# Prerequisites
1. Google Cloud project configured with access to the Google Sheets API  
and Google Drive API services.
2. API key registered on the Wonca Labs platform (link: https://www.wonca.com.br/)

# Preparation
1. Creating the navegation path:  
Using pyautogui for browser navigation automation, is required prepare the windows  
that's gonna be used. Map out the path the script will follow, taking into account  
factors that cause the flow to branch during navigation. 

2. Screenshots base:  
Store images and assign confidence values ​​so that the script can locate them  
without issues when they are clearly visible.

# How use
1. The user prepares the browser environment with the browsing tabs ready and selects 
the executable Python file created by the PyInstaller library. 

2. Ensure that computer 
usage (mouse, keyboard) does not interfere with the script's operation.

# Technologies
This project is 100% based on python language.
